# Speedometer

Build a simple iOS-style GPS Speedometer landing page inspired by the reference: clean Apple-like design, large live speed display, analog/digital toggle, km/h/mph/m/s/knots units, Start/Stop button, max speed, average speed, distance and trip time. Use the device’s free browser GPS/Geolocation API for real-time speed and OpenStreetMap for the map, with no paid APIs or API keys. Make it responsive, minimal, smooth, and optimized for iPhone Safari/PWA.
